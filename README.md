# Multilingual Financial Query Engine

An AI/ML proof-of-concept for HisabDo that allows users to ask financial questions in English, Urdu, Roman Urdu, and mixed language.

## Features

- Multilingual financial queries
- Gemini-powered query understanding
- FastAPI backend
- Structured input validation
- AI response validation
- Error handling
- Customer balance queries
- Expense analysis
- Outstanding customer queries

## Tech Stack

- Python
- FastAPI
- Gemini API
- Pandas
- Uvicorn
